## Mathematical Foundations

The repository contains detailed explanations and proofs of various mathematical concepts. The main files include:

- `Ackermann.v`: Implementation of the Ackermann function.
- `Deduction.v`: Proofs related to deduction.
- `Formulas.v`: Definitions and proofs related to formulas.
- `IntuitCompleteness.v`: Proofs related to intuitionistic completeness.
- `PredicateCalculus.v`: Implementation of predicate calculus.
- `PropIntuit.v`: Proofs related to propositional intuitionism.
- `PropLang.v`: Definitions and proofs related to propositional logic.
- `Propositional.v`: Implementation of propositional logic.
- `Provability.v`: Proofs related to provability.
- `Terms.v`: Definitions and proofs related to terms.
- `Translation.v`: Proofs related to translation.
- `Valuation.v`: Definitions and proofs related to valuation.
- `Vec.v`: Implementation of vectors.

## Software Implementations

The repository also contains implementations of mathematical algorithms and data structures. The main files include:

- `compile.cpp`: C++ implementation of a compiler.
- `eqb_nat.v`: Implementation of natural numbers.
- `makefile`: Makefile for building the project.
- `runme.bat`: Batch file for running the project.
